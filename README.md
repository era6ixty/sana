# Sana

Личное приложение для заучивания карточек по истории Казахстана. Карточки
генерируются из PDF серии «база смарт» локальным конвертером, прогресс хранится
в браузере через IndexedDB. Без аккаунтов, бэкенда и синхронизации.

## Быстрый старт

Нужен Node.js 22 и Python 3 (для конвертера).

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`. При первом запуске приложение само загрузит
`public/deck.json` в IndexedDB. Если файла нет, появится экран загрузки колоды —
это же поведение используется в публичной сборке без текста книги.

Сборка и локальный предпросмотр:

```bash
npm run build
npm run preview
```

## Конвертация PDF

```bash
python3 tools/convert.py "/путь/к/книге.pdf" -o public/deck.json
```

Конвертер использует `pdftohtml` из poppler-utils:

```bash
sudo apt install poppler-utils
```

Что делает скрипт:

- читает XML-разметку страниц и склеивает строки вопроса/ответа;
- определяет разделы по крупным заголовкам `§...`;
- пропускает оглавление и страницы, где нет нормальных пар вопрос-ответ
  (таблицы и вставки — пока не поддерживаются);
- убирает дубли, нормализует казахские буквы и римские цифры;
- ставит флаги `long`, `short`, `mixed`, `no_colon`, `multi` для ручной проверки.

После конвертации перезапустите приложение или нажмите в настройках
«Пересобрать из deck.json». **Пересборка сбрасывает прогресс.**

Текущая книга: 717 карточек, 8 разделов, 16 карточек с пометками (в основном
длинные цитаты и вопросы с несколькими ответами).

`public/deck.json` намеренно не добавлен в git: текст книги не должен утечь
при публикации репозитория. После клонирования его нужно сгенерировать
конвертером.

## Учёба

- **Учить** — новые карточки и просроченные, сессия до 30 штук.
- **Повторение** — карточки, срок которых наступил; четыре оценки FSRS с
  прогнозом интервала.
- **Тест** — 20 случайных вопросов с вариантами, не влияет на расписание.
- **Настройки** — экспорт/импорт JSON, сброс прогресса, пересборка базы.

Клавиатура: пробел — перевернуть карточку, `1`–`4` — оценить.

Данные лежат только в текущем браузере. Для переноса или бэкапа используйте
экспорт JSON в настройках. Очистка данных сайта удалит прогресс.

## Деплой

Проект — обычная статика Vite. Есть несколько режимов сборки:

- `npm run build` — обычная сборка вместе с `public/deck.json` (для локального
  использования и закрытого хостинга).
- `npm run build:public` — сборка **без текста книги**: `deck.json` удаляется из
  `dist`, а при первом открытии приложение просит загрузить файл вручную.
- `npm run build:pages` — то же для GitHub Pages: базовый путь `/sana/`,
  `404.html` для клиентских маршрутов и `.nojekyll`.

### GitHub Pages

Публичная версия: **https://era6ixty.github.io/sana/**

Деплой настроен в `.github/workflows/deploy.yml`: каждый push в `main` собирает
приложение через `npm run build:pages` и публикует `dist` без колоды. Workflow
сам включает Pages (Source: GitHub Actions) и проверяет, что `dist/deck.json`
не попал в артефакт.

При первом открытии сайта нажмите «Выбрать deck.json» и укажите файл,
созданный конвертером. Он сохранится в IndexedDB этого браузера. Для новой
книги используйте «Настройки → Книга → Новая книга».

Так на хостинге лежит только код приложения, без текста учебника. Прогресс
по-прежнему локальный: на другом устройстве колоду нужно загрузить заново, а
прогресс переносится через экспорт/импорт резервной копии.

### Vercel

В `vercel.json` уже заданы `npm run build:public` и `dist`; `.vercelignore`
не даёт загрузить `public/deck.json` в облако. Достаточно импортировать
репозиторий в Vercel (Framework Preset: Vite).

⚠️ **Авторские права.** `public/deck.json` содержит текст учебного пособия.
Не добавляйте его в git и не публикуйте. Для полностью закрытого доступа можно
дополнительно поставить пароль или Cloudflare Access.

## Структура

```
public/deck.json        сгенерированные карточки (не в git)
src/pages/              главная, раздел, учёба, повторение, тест, настройки
src/components/         UI-компоненты и первый запуск без колоды
src/db.ts               Dexie, первичное заполнение, импорт/экспорт
src/lib/srs.ts          обёртка над ts-fsrs 5.4
tools/convert.py        PDF -> deck.json
.github/workflows/      сборка и деплой на GitHub Pages
.vercelignore           исключает колоду из публичной сборки
```
