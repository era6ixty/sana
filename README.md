# Sana

Личное приложение для заучивания карточек по истории Казахстана. Карточки
генерируются из PDF серии «база смарт» локальным конвертером, прогресс хранится
в браузере через IndexedDB. Без аккаунтов, бэкенда и синхронизации.

## Быстрый старт

Нужен Node.js 22 и Python 3 (для конвертера).

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`. При первом запуске приложение само загрузит
`public/deck.json` в IndexedDB.

Сборка и локальный предпросмотр:

```bash
npm run build
npm run preview
```

## Конвертация PDF

```bash
python3 tools/convert.py "/путь/к/книге.pdf" -o public/deck.json
```

Конвертер использует `pdftohtml` из poppler-utils:

```bash
sudo apt install poppler-utils
```

Что делает скрипт:

- читает XML-разметку страниц и склеивает строки вопроса/ответа;
- определяет разделы по крупным заголовкам `§...`;
- пропускает оглавление и страницы, где нет нормальных пар вопрос-ответ
  (таблицы и вставки — пока не поддерживаются);
- убирает дубли, нормализует казахские буквы и римские цифры;
- ставит флаги `long`, `short`, `mixed`, `no_colon`, `multi` для ручной проверки.

После конвертации перезапустите приложение или нажмите в настройках
«Пересобрать из deck.json». **Пересборка сбрасывает прогресс.**

Текущая книга: 717 карточек, 8 разделов, 16 карточек с пометками (в основном
длинные цитаты и вопросы с несколькими ответами).

## Учёба

- **Учить** — новые карточки и просроченные, сессия до 30 штук.
- **Повторение** — карточки, срок которых наступил; четыре оценки FSRS с
  прогнозом интервала.
- **Тест** — 20 случайных вопросов с вариантами, не влияет на расписание.
- **Настройки** — экспорт/импорт JSON, сброс прогресса, пересборка базы.

Клавиатура: пробел — перевернуть карточку, `1`–`4` — оценить.

Данные лежат только в текущем браузере. Для переноса или бэкапа используйте
экспорт JSON в настройках. Очистка данных сайта удалит прогресс.

## Деплой

Проект — обычная статика Vite. Для Vercel:

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- `vercel.json` уже содержит rewrite на `index.html` для клиентских маршрутов.

⚠️ **Авторские права.** `public/deck.json` содержит текст учебного пособия.
Публичный деплой означает, что файл сможет скачать любой, кто знает адрес.
Для личного использования лучше:

1. запускать локально;
2. закрыть деплой паролем/Cloudflare Access;
3. либо не включать `deck.json` в публичную сборку и загружать его вручную.

Не выкладывайте колоду в открытый доступ.

## Структура

```
public/deck.json        сгенерированные карточки
src/pages/              главная, раздел, учёба, повторение, тест, настройки
src/components/         UI-компоненты
src/db.ts               Dexie, первичное заполнение, импорт/экспорт
src/lib/srs.ts          обёртка над ts-fsrs 5.4
tools/convert.py        PDF -> deck.json
```
